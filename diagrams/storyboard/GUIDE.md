# ストーリーボード(動作説明)

バス構成図をそのまま使い回し、ステップごとのコマに矢印を重ねて 1 枚に並べる。
仕様書の「動作説明」節に置く図。各コマにタイトル・主体(マスタ)・説明文(レイテンシ目安)が付く。

## 入力
バス構成図と同じ spec YAML。次のどちらかがあればコマになる。
- `scenario.steps` … 手書きの動作ステップ(`title` `master` `note` `flows`)
- `latency.accesses` … アクセスごとに 1 コマ。経路の矢印・ホップごとのサイクル・合計が自動で付く

並べ方は `storyboard:` で指定(省略可):
```yaml
storyboard:
  title: 推論1回の処理
  cols: 2            # 1 行のコマ数
  crop: union        # union(既定)/ auto / full
  width: 620         # コマの幅 px
  aspect: 1.33       # コマの縦横比(省略時は図に合わせる)
```

## 手順
1. バス構成図のチェック(lint OK)を先に通す。ストーリーボードは同じ図を使うので、図の問題はコマ全部に出る。
2. ステップが未決なら質問する(何を説明したいか・主体・順番)。決まっていないステップは仮置きで `note` に「仮」と書く。
3. 生成: `python3 scripts/storyboard.py spec.yaml -o out/ --png`
4. PNG を見て、矢印・文字が読めるか、コマ間で縮尺が揃っているかを確認する。

## 描き方の決まり(R47)
- 図はコマごとに描き直さず、同じ構成図を使い回す(ブロックの位置が動かないので差分だけが目に入る)。
- 既定 `crop: union` = 全ステップで動く所をまとめた範囲を、全コマ同じ切り出し・同じ縮尺で出す。
- 縦長の図はコマも縦長にし、横に 4 コマまで並べる。
- 図が大きくて共通範囲では文字が読めない場合は自動で `crop: auto`(コマごとに寄る)に切り替え、横長のコマを 1 列で並べる。縮尺がコマごとに違う旨を info で出す。
- コマの間に進む向きの小さな矢印。説明文はコマ下に折り返して入れる。
- レイテンシのあるステップは説明文に「到着 / 戻るまで」のサイクルと ns 換算。既定値を使った所は「※既定値を含む」。

## チェック
- コマごとの文字の重なり(lint)。
- バス構成図側の警告(既定値の注意・info は除く)。
